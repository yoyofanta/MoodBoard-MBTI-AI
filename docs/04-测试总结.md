# MoodBoard 测试总结

## 1. 测试目标

验证课程项目在默认 mock AI 配置下能够构建、启动并完成核心 API 流程；记录功能测试、自动化测试和缺陷回归的真实状态，为最终浏览器验收提供基线。

## 2. 测试范围

- 登录、注册与用户资料
- 情绪日记新增、按日期读取、修改、周/月/年查询与删除
- AI/Memory Chat、RAG 知识检索与问答
- 位置工具调用
- 多 Agent 圆桌及参数异常
- 前端 TypeScript/Vite 正式构建
- 后端 Spring Boot 测试与打包

浏览器交互、真实 DeepSeek、真实高德定位、移动端兼容性和本地图片持久化尚未进行本轮人工回归。

## 3. 测试环境

| 项目 | 实际环境 |
| --- | --- |
| 操作系统 | Windows |
| 前端 | Vue 3、TypeScript、Vite |
| 后端 | Spring Boot 3.3.5、Java 17 目标版本 |
| 数据库 | H2；自动化测试使用独立内存库 |
| AI | 默认 `AI_MODE=mock`，未调用真实 DeepSeek |
| 地图 | 未配置真实 `AMAP_KEY` |
| 自动化 | JUnit/Spring Boot Test、Python pytest + requests |

## 4. 测试方法

- Excel 功能用例与缺陷记录审计
- Spring MockMvc 集成测试
- pytest HTTP API 自动化
- `vue-tsc --noEmit` 与 Vite production build
- Maven test/package
- API 路径和密钥模式静态检查

## 7. 后端集成测试结果

`mvn test` 成功。当前 1 个 Spring Boot/MockMvc 集成测试通过，覆盖日记新增、按日期读取、更新、周/月/年查询、删除、删除后不存在及无效 ID 返回 404。

## 8. 前端构建验证

构建成功不等同于所有浏览器交互均已验证。
