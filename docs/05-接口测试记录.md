## 五、本轮自动化复验

在原有 Python requests 接口测试脚本基础上，使用 pytest 组织 13 项 API 测试。本轮在 `AI_MODE=mock` 和独立内存 H2 下重新执行，不调用真实 DeepSeek 或高德服务。

测试文件：

```text
tests/test_api_pytest.py
tests/api_test.py
```

执行命令：

```bash
py -m pytest tests/test_api_pytest.py -q
```

真实结果：`13 passed in 0.47s`。

覆盖注册、登录、错误密码、资料读取/保存、Memory Chat、Memory 读取/清空、知识检索、RAG 问答、位置工具、Agent 圆桌及 Agent 数量异常。该结果证明对应 API 在 mock 环境中通过，不代表浏览器交互、real DeepSeek 或真实高德定位已完成回归。
